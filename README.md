###  Getting Started & Prerequisites

To follow this course, you need to set up your coding environment. Please complete the following steps before the first class:

1.  **Install an IDE**: Download and install [Visual Studio Code (VS Code)](https://visualstudio.com).
2.  **Install Python**: Download the latest stable version from [python.org](https://python.org). 
    *   *⚠️ **Windows Users:** Make sure to check the box **"Add python.exe to PATH"** at the bottom of the installer window before clicking "Install Now".*
3.  **Install the Python Extension**: Open VS Code, go to the Extensions tab (`Ctrl+Shift+X` or `Cmd+Shift+X`), search for **Python** (by Microsoft), and click Install.
4. Create a small ***hello.py*** script with the following command : `print("Hello world!")`. Save the file and press the play button ( top right corner) to run the script. You should see Hello world! in the terminal.
